# UAT: v0.8.0 (#62, #63, #65 together)

About 20 minutes, on one test build that has all three stories. You test; nothing merges until you say so. #66
needs no steps from you: its tests and CI are the check. The automated tests already cover the edge cases (bad
`VERSION` files, every threshold and setting error, the log contents), so these steps are only what a person has
to see.

## Setup
1. Build a test copy of the top of the stack in its own folder, outside the live install:
   `.\tools\New-TestBuild.ps1 -Ref feature/65-drive-full -Destination <test folder>`
2. Start it with `<test folder>\Start SRRVRR.bat`. Say **No** to the administrator prompt. It listens on port
   8091; the live copy keeps running on its own port.
3. Open `http://localhost:8091/`. On the Storage card, pick the fullest drive that is at least 50% used and note
   its used percent rounded down, N.

To change a setting below: stop the test copy with `<test folder>\Stop SRRVRR.bat`, edit
`<test folder>\SRRVRR.config.psd1` (it already holds `Port = 8091`: add or change lines inside the `@{ }`, and
don't replace the file), then start it again. **Leave the page open and don't refresh it** while you do: it
reconnects by itself, and banners only show for events that happen while a page is open.
