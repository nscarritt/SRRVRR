# UAT: v0.10.0, the workstation (#90, #91, #92, #93 together)

About 40 minutes: part A (the Workstation role, on your PC) about 30, part B (the Server role, on the server)
about 10. Both parts use the same build, the top of the four stacked branches, so one test copy has all four
stories. You test; nothing merges until you say so. #94 (release and install) needs no steps from you. The
automated tests already cover the edge cases (every state change of the AI server card, the spill rule's
thresholds and hold times, the `nvidia-smi` and `.wslconfig` parsing, every setting error, what the AI server
reader may and may not send), so these steps are only what a person has to see.

You need, for part A: the PC's graphics card, the AI server you normally run (ComfyUI inside WSL) with a job
you can queue that runs at least a minute, Task Manager, and `nvidia-smi` (it comes with the graphics driver).
Close games and anything else that holds the graphics card first, and start with the AI server **stopped**.

## Setup, part A: the Workstation role on your PC
1. Build a test copy of the top of the stack in its own folder, outside the live install:
   `.\tools\New-TestBuild.ps1 -Ref feature/93-ai-server -Destination <test folder>`
   Note the commit it prints: it goes in the Results line.
2. Stop the test copy if it is running, then edit `<test folder>\SRRVRR.config.psd1`. It already holds
   `Port = 8091`: add two lines inside the `@{ }` and don't replace the file:
   `Role = 'Workstation'` and a `ComfyUi` entry for each UI your AI server runs, such as
   `ComfyUi = @(@{ Name = 'Main'; Port = 8188 })` (8188 is ComfyUI's default; names are 1 to 20 characters).
3. Start it with `<test folder>\Start SRRVRR.bat`. Say **No** to the administrator prompt. It listens on port
   8091 on this PC only; the live copy keeps running on its own port. **Keep its console window where you can
   read it.** Open `http://localhost:8091/`, and turn the page's sound on (click the sound button once).

To change a setting or restart the copy: stop it with `<test folder>\Stop SRRVRR.bat`, then start it again. The
page reconnects by itself.
